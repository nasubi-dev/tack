# Tack

⌃⌥P で前面のウィンドウを常に手前にピン留めする macOS メニューバーアプリ。

macOS には他アプリのウィンドウを最前面に固定する公開 API がないため、対象ウィンドウを ScreenCaptureKit で取り込んで浮いたパネルに映している（Topit と同じ方式）。

## 使い方

- **⌃⌥P**: 前面のウィンドウをピン留め。ピン留め中に押すと（どのアプリが前面でも）解除
- 2 枚目以降はメニューバーの 📌 →「前面のウィンドウを追加でピン留め」
- パネルをドラッグすると移動、端を引っぱるとリサイズ（縦横比は固定）
- パネルをクリックすると本物のウィンドウがその位置に出て操作できる。別のアプリに移るとパネルに戻る
- 左上の × かメニューバーの 📌 から解除
- 📌 →「ログイン時に起動」で自動起動を切り替え（初回起動時にオンになる）

## ビルド

```sh
./build.sh   # ~/Applications/Tack.app に入る
```

初回は次の 2 つを許可する。

- 画面収録とシステムオーディオ録音（必須。許可後に Tack を再起動）
- アクセシビリティ（クリックで本物のウィンドウを出す機能に使う）
